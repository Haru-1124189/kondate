# こんだて

1週間分の夕食の献立を決めて、週末にまとめて買い物するための Web アプリです。
2人で同じ献立と買い物リストを共有できます（保存先は自分の Google スプレッドシート）。

- **献立**：月〜日の夕食に料理を入れる。日ごとにメモ（外食・残り物など）も書ける
- **買い物**：その週の料理の材料を自動で集計（「玉ねぎ 1個＋2個 → 3個」のように合算）。洗剤など手動で足すこともできる。チェックは2人で共有
- **料理**：よく作る料理と材料を登録しておく。最近作っていない順に出てくるので、マンネリ防止にもなる

土日に開くと、自動で来週の献立が表示されます。

---

## セットアップ

### 1. スプレッドシートと Apps Script を用意する（最初の1回だけ）

1. [Google スプレッドシート](https://sheets.new) で新しいシートを作る（名前は「こんだて」など何でもOK）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っているコードを全部消して、[`gas/Code.gs`](gas/Code.gs) の中身をまるごと貼り付ける
4. 上の方にある `const PASSWORD = 'ここを合言葉に変える';` の部分を、好きな合言葉に変える
   （例：`'kondate-2026-nekochan'`。推測されにくいものにしてください）
5. 💾 保存
6. 右上の **デプロイ → 新しいデプロイ**
   - 歯車 ⚙ → 種類「**ウェブアプリ**」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押す
7. 「アクセスを承認」→ 自分の Google アカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら **詳細 → （安全ではないページ）に移動** で進めてOK（自分で作ったスクリプトなので問題ありません）
8. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー

### 2. アプリに設定する

1. アプリを開いて **⚙️ 設定** タブ
2. 「Apps Script の URL」と「合言葉」を入れて **保存して接続**
3. 右上の丸が 🟢 緑になれば同期できています

### 3. 相手のスマホを設定する

設定タブの **設定リンクを送る** で、LINE などに送ります。相手がそのリンクを開くだけで設定が終わります。
（リンクには合言葉が入っているので、他の人には送らないでください）

### 4. ホーム画面に追加する（おすすめ）

- iPhone：Safari で開く → 共有ボタン → **ホーム画面に追加**
- Android：Chrome で開く → ︙ → **ホーム画面に追加**

アプリのように起動できます。

## よくあること

- **Code.gs を書き換えたとき**：デプロイ → デプロイを管理 → ✏️ → バージョン「新しいバージョン」→ デプロイ。（「新しいデプロイ」を作ると URL が変わってしまいます）
- **同期されない**：右上の丸が 🔴 赤ならタップすると理由が出ます。電波が悪いときは、つながった時点で自動で送り直します
- **データの中身を見たい**：スプレッドシートの `data` シートに入っています。「内容（見る用）」列で何のデータか分かります。直接書き換えるのはおすすめしません
- **バックアップ**：設定タブの「ファイルに書き出す」で JSON ファイルとして保存できます

## しくみ

- アプリ本体は HTML/CSS/JS だけの静的サイト（GitHub Pages）
- データはキーごとに Apps Script 経由でスプレッドシートへ保存。2人が同時に別のものを編集しても上書きし合いません
- 端末にもキャッシュしているので、電波がなくても見られます
- Apps Script の URL と合言葉はリポジトリには含まれず、各端末のブラウザにだけ保存されます
